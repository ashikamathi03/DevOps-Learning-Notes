# Shell Commands:-
## Navigation

* `pwd` → Shows current directory
* `ls` → Lists files and directories
* `cd` → Changes directory
* `cd ..` → Goes to parent directory
* `cd ~` → Goes to home directory

## Files & Directories

* `mkdir` → Creates a directory
* `touch` → Creates an empty file
* `cp` → Copies files/directories
* `mv` → Moves or renames files
* `rm` → Removes files
* `rmdir` → Removes an empty directory

## View Files

* `cat` → Displays file contents
* `less` → Views large files
* `head` → Shows beginning of a file
* `tail` → Shows end of a file
* `tail -f` → Continuously monitors a file

## Search

* `find` → Finds files/directories
* `grep` → Searches text inside files
* `which` → Shows location of a command

## System Information

* `whoami` → Shows current user
* `hostname` → Shows system/host name
* `uname` → Shows system information
* `date` → Shows date and time
* `df -h` → Shows disk space
* `du -sh` → Shows directory size
* `free -h` → Shows memory usage

## Process Management

* `ps` → Shows running processes
* `top` → Monitors processes and resource usage
* `kill` → Sends a signal to a process
* `jobs` → Shows background jobs
* `bg` → Runs a stopped job in background
* `fg` → Brings a job to foreground

## Useful Commands

* `clear` → Clears terminal screen
* `history` → Shows previously used commands
* `man` → Opens command manual
* `echo` → Displays text
* `sudo` → Runs a command with elevated privileges
